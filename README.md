# Portfólio profissional

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio profissional
utilizando HTML5 e CSS3 para a disciplina Design Profissional do curso
de Análise e Desenvolvimento de Sistemas.

O portfólio apresenta informações acadêmicas, competências técnicas,
competências comportamentais, projetos e formas de contato.

## Objetivos

- Apresentar meu perfil profissional.
- Demonstrar conhecimentos em desenvolvimento web.
- Apresentar projetos acadêmicos.
- Disponibilizar informações sobre minha formação.
- Praticar HTML5 e CSS3.
- Publicar o portfólio utilizando GitHub Pages.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
